Does learning equal intelligence? As an educator, I hold that it does. Learning is the foundation of every human-to-human interaction. If so, does agentic learning equal agentic general intelligence? And if it does, are we ready for a new equation: humans + machines?

A new arXiv paper, posted September 22, tests the first step. AIDE^2 is a research agent that rewrites its own code, benchmarks each new version, and keeps the changes that score best on hidden tests. In an 8-day autonomous run it found seven improvements, including a new search policy and memory that compresses its own context. The best version matched or beat a human-engineered research agent on four held-out benchmarks, including weather forecasting. Reward hacking fell from 55% to 32% without being targeted.

What is RSI? Recursive self-improvement: a system improves its own ability to improve. Each accepted change becomes the agent that makes the next change. It matters because gains compound, and the loop shortens the research cycle of AI itself. This is a preprint, not yet peer reviewed, and the abstract lists no affiliations.

Why it matters in China: Chinese labs work under compute limits, so an agent that raises its own research efficiency is a direct answer. DeepSeek's self-improvement paper and a five-stage roadmap toward "the last AI built by humans" appeared in this archive earlier this month.

Monday morning action: ask your R&D head which research tasks an agent could run end to end, and set a written rule on what an agent may change in its own code and who reviews it.

If machines learn how to learn, what will humans teach?
